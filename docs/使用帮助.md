# Codex Hybrid 使用帮助

## 1. 什么时候使用

适合以下场景：

- 希望由 Sol 统一分析需求，并把不同类型的工作交给不同模型。
- 需要让多个执行代理明确各自可以修改的文件，降低并发覆盖风险。
- 希望统一管理 Codex CLI 和 IDE 使用的代理、技能、服务提供商和密钥。
- 需要可备份、可回滚、可卸载的本地协作配置。

不适合以下场景：

- 只想临时调用一个模型完成一次简单问答。
- 还没有确认服务提供商协议、模型权限或 API 密钥是否可用。
- 需要自动修改生产环境、数据库或其他不可逆资源。

## 2. 安装

### 2.1 前置条件

- macOS。
- 已安装并登录 Codex CLI。
- 已准备 ZAI Coding Plan API 密钥。

### 2.2 安全预演

先查看安装器将要检查的内容，不写入文件：

~~~sh
bash ./install.sh --dry-run
~~~

### 2.3 正式安装

~~~sh
export ZAI_API_KEY='你的 ZAI Coding Plan 密钥'
bash ./install.sh --set-default
~~~

安装器会：

1. 检查系统、Codex CLI 和现有配置。
2. 创建时间戳备份。
3. 写入受管服务提供商配置、Luna/GLM 代理和 `hybrid-dev` 技能。
4. 将密钥保存到 `CODEX_HOME/secrets/zai_api_key`，权限设为 600。
5. 使用本地认证辅助程序向 Codex 提供密钥。
6. 验证 TOML、JSON、代理文件和 Codex 配置。

如果 `CODEX_HOME` 不是默认位置，先设置：

~~~sh
export CODEX_HOME="$HOME/.codex"
~~~

### 2.4 安装选项

~~~sh
# 替换已有的 codex-hybrid 管理文件
bash ./install.sh --force

# 修改 GLM 执行代理使用的模型
bash ./install.sh --glm-model glm-4.7

# 显式启用与当前 Codex 版本匹配的模型目录
bash ./install.sh --catalog-path /绝对路径/models.json

# 检查安装包版本
bash ./install.sh --version v0.2.0
~~~

`--force` 只应在确认冲突文件可以被替换时使用。安装器会先创建备份。

## 3. 如何选择执行代理

### Sol

负责需求理解、代码分析、任务拆分、路由、整合和最终评审。需要修改共享入口、公共接口、架构或安全配置时，由 Sol 先判断。

### Luna

适合探索、测试补充、文档、单文件机械修改、格式修复和已知根因的小问题。

### GLM

适合跨文件主体实现、完整功能、较大重构和复杂调试后的实现。只有服务提供商可用、任务独立且允许发送相关仓库上下文时才启用。

两个执行代理不能同时拥有同一个文件。共享文件由 Sol 或指定的单个执行代理负责整合。

## 4. 模型扩展

### 4.1 使用同一服务提供商的其他模型

当前 GLM 执行代理支持模型覆盖：

~~~sh
bash ./install.sh --glm-model glm-4.7
~~~

也可以使用环境变量：

~~~sh
GLM_MODEL=glm-4.7 bash ./install.sh
~~~

实际使用前仍需确认模型权限、上下文限制、工具调用和 `reasoning_effort` 兼容性。

### 4.2 增加新的服务提供商或角色

需要同时增加：

- 独立的服务提供商配置和认证方式。
- 模型配置档案与当前 Codex 版本匹配的模型目录。
- 新的代理 TOML 和技能路由规则。
- 离线配置验证及独立网络冒烟测试。

不要只把模型名称写入配置；协议、密钥、工具调用和流式输出都必须单独验证。

## 5. 验证

运行离线测试：

~~~sh
bash tests/install-smoke.sh
bash tests/rollback-smoke.sh
bash tests/uninstall-smoke.sh
bash tests/workflow-smoke.sh
~~~

服务提供商网络测试会发送真实请求，可能产生费用，必须显式确认：

~~~sh
bash tests/provider-smoke.sh --confirm-network --model glm-5.2
~~~

如果出现 404、协议错误或模型不可用，应记录为 `BLOCKED`，不能改写成安装成功。

## 6. 卸载与恢复

默认卸载会移除本方案管理的文件，并把密钥和受管文件移动到备份目录：

~~~sh
bash ./uninstall.sh
~~~

如需永久删除当前密钥：

~~~sh
bash ./uninstall.sh --purge-secret
~~~

卸载不会删除整个 `CODEX_HOME`，也不会处理其他代理、MCP、Hook 或项目配置。

## 7. 常见问题

### 安装提示服务提供商冲突

说明 `config.toml` 中已有同名但不受本方案管理的配置块。请先审阅差异；确认要替换时再使用 `--force`，否则保留原配置并停止安装。

### 安装提示缺少 API 密钥

交互安装可以在终端中输入密钥；自动化安装请设置：

~~~sh
export ZAI_API_KEY='你的密钥'
~~~

不要把真实密钥写入命令历史、仓库、TOML、日志或提交记录。

### GLM 网络测试返回 404 或协议错误

先确认服务商端点、账号套餐和模型权限。当前安装成功只代表本地配置可被 Codex 解析，不代表网络协议已经兼容。

### 修改技能后没有生效

重启 Codex 会话，使用户级 `$HOME/.agents/skills/hybrid-dev/SKILL.md` 重新加载。
